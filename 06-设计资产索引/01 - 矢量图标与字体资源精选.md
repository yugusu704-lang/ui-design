# 矢量图标与字体资源精选 (Icons & Fonts)

> 整理自全球顶级开源设计资源库 `bradtraversy/design-resources-for-developers`。
> 专注于为**移动端 UI 设计与 Vibe Coding** 提供高辨识度、低体积、高灵活度的矢量图标集与开源系统字体。

---

## 💎 顶级移动端矢量图标库 (Icon Sets)

移动端图标要求：**矢量可缩放 (SVG/WebFont)、统一网格基准 (16/24/32px)、支持 Outline 与 Solid 两种激活态**。

| 图标库名称 | 官方链接 | 规格基准 | 授权类型 | 移动端适用场景与特色 |
| :--- | :--- | :--- | :--- | :--- |
| **Lucide Icons** | [lucide.dev](https://lucide.dev/) | 24×24px (2px 描边) | ISC (完全商用开源) | **现代 UI 首选**。Feather 官方超强维护分支，支持 React Native / Flutter / Web，线条锐利通透，完美适配现代极简与 Linear 风格。 |
| **Phosphor Icons** | [phosphoricons.com](https://phosphoricons.com/) | 16/24/32px | MIT | **状态最丰富**。提供 Regular, Thin, Light, Bold, Fill, Duotone 六种权重，极其适合作为移动端 TabBar 选中切换与高触觉按钮。 |
| **Heroicons** | [heroicons.com](https://heroicons.com/) | 20/24px | MIT | **Tailwind 官方出品**。针对 24px Outline 和 20px Solid 深度优化，非常契合移动端列表行操作项及表单校验反馈。 |
| **Tabler Icons** | [tabler.io/icons](https://tabler.io/icons) | 24×24px | MIT | **量级庞大 (5000+)**。涵盖工具类、物联网、音视频控制，高度一致的几何比例，适合复杂工具型或效率型 App。 |
| **Remix Icon** | [remixicon.com](https://remixicon.com/) | 24×24px | Apache 2.0 | **国内双语与出海优选**。每一个图标均配备严格对齐的 Line 和 Fill 两种版本，常用于国内主流商用移动端体系。 |
| **Iconoir** | [iconoir.com](https://iconoir.com/) | 24×24px | MIT | 具备独立个性的几何现代感，原生支持 Figma、React Native、Swift，适合设计驱动型独立应用。 |

### 📱 移动端图标工程实践建议
- **触控面积补足**：即使视觉图标为 `20×20px` 或 `24×24px`，外层点击容器必须通过 `padding` 扩张至最小 `44×44px`（iOS）或 `48×48px`（Android），遵守 [[01 - 菲茨定律 (Fitts's Law) 与触控靶心]]。
- **状态表达**：底层导航 TabBar 建议采用“未选中为 Outline，选中激活为 Solid/Fill + 主题高亮”，增强认知深度。

## 🔠 顶级移动端开源字体排印 (Typography)

移动端屏幕空间紧张，优先选用**字怀开阔、大 x-height、字符间距清晰、视网膜屏渲染锐利**的无衬线体与等宽字体。

| :--- | :--- | :--- | :--- | :--- |
| **Inter** | [rsms.me/inter](https://rsms.me/inter/) | 无衬线体 (UI专用) | 西文 | **UI 界面天花板**。专为高 DPI 屏幕与小字号微排版打造，带 Contextual Alternates，数字等宽对齐出色。 |
| **Geist** | [vercel.com/font](https://vercel.com/font) | 无衬线 / 等宽 | 西文 | Vercel 现代极客排版代表，严苛的几何比例与高级中性冷感，适合开发者工具与 AI 交互客户端。 |
| **Plus Jakarta Sans** | [Google Fonts](https://fonts.google.com/specimen/Plus+Jakarta+Sans) | 现代无衬线体 | 西文 | 几何形态兼具亲和力，圆润微弧度，非常适合金融科技、SaaS 移动端标题与品牌感知展示。 |

| **HarmonyOS Sans** | [developer.harmonyos.com](https://developer.harmonyos.com/) | 移动动态黑体 | 中文/多语言 | **免费商用**。高易读性、动态字重可调节，在小屏密集信息流场景下辨识度极其卓越。 |
| **JetBrains Mono** | [jetbrains.com/mono](https://jetbrains.com/mono/) | 等宽编程体 | 代码/西文 | 移动端技术类展示首选，连字特性 (Ligatures) 清晰，数字与符号辨识度防混淆。 |
