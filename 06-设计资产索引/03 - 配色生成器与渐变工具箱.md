# 配色生成器与渐变工具箱 (Color Palette & Gradient Generators)

> 整理自全球顶级开源设计资源库 `bradtraversy/design-resources-for-developers`。
> 移动端色彩系统不仅决定品牌性格，更直接受制于**户外强光、OLED 像素发光、暗黑模式对比度及 WCAG 2.1 可访问性标准**。

| :--- | :--- | :--- | :--- |
| **Realtime Colors** | [realtimecolors.com](https://realtimecolors.com/) | **整页实时预览** | 可实时将生成的调色板直接映射到模拟 UI 组件（按钮、卡片、输入框、Tab导航），所见即所得检测对比度。 |

## 🌈 移动端渐变与流光引擎 (Gradients & Mesh)

渐变常用于移动端**顶部沉浸式导航头、会员金卡高光、FAB 浮动按钮与微光边框**。

| 工具名称 | 官方站点 | 表现形式 | 代码导出能力 |
| :--- | :--- | :--- | :--- |
| **CSS Gradient** | [cssgradient.io](https://cssgradient.io/) | 经典线性与径向渐变 | 纯 CSS `linear-gradient` / `radial-gradient` |
| **Mesh Gradient** | [meshgradient.in](https://meshgradient.in/) | 复杂多锚点网格弥散流光 | 支持 SVG 滤镜代码与无损高斯模糊图层 |
| **Hypercolor** | [hypercolor.dev](https://hypercolor.dev/) | 专为 Tailwind 优化的现代预设 | 一键拷贝 `bg-gradient-to-r from-cyan-500 to-blue-500` 类名 |
| **Gradients.app** | [gradients.app](https://gradients.app/) | 精选 iOS 风格双色微渐变 | 导出 Swift UIColor、Android XML 及 CSS 格式 |

## 🛡️ 移动端色彩落地的三大红线 (Color Constraints)

1. **文字对比度铁律 (WCAG AA/AAA)**：
   - 标题级文字（≥ 18pt 或加粗 14pt）：与背景对比度不得低于 `3:1`。
   - 正文与小标签文字（< 18pt）：对比度必须达到 `4.5:1` 以上（推荐达标 `7:1`）。
2. **纯黑禁忌 (`#000000` vs `#0B0D0E`)**：
   - 在暗黑模式（Dark Mode）下，避免大面积使用绝对纯黑 `#000000` 配合刺眼纯白 `#FFFFFF`（会造成剧烈眩光与视疲劳）。建议使用高阶深灰 `#0F172A` 或黑曜石灰 `#0B0D0E`，并对文字采用 `#F8FAFC`。
3. **功能色彩与情感习惯**：
   - 危险/删除：恒定绑定红系（如 `#EF4444`）；
   - 成功/已完成：恒定绑定绿系（如 `#10B981`）；
   - 警示/待确认：琥珀橙系（如 `#F59E0B`）。
