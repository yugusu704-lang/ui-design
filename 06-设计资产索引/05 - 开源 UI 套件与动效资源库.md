# 开源 UI 套件与动效资源库 (UI Kits & Motion Libraries)

> 整理自全球顶级开源设计资源库 `bradtraversy/design-resources-for-developers`。
> 优秀的移动端体验不仅是静态视图，更在于触控反馈时的**物理弹性、状态流转（Transition）与微动效（Micro-interactions）**。

## 🎬 移动端矢量动画与微交互引擎 (Motion & Animation)

| 工具/库名称 | 官方站点 | 技术体系 | 移动端落地场景 |
| :--- | :--- | :--- | :--- |
| **Rive** | [rive.app](https://rive.app/) | 实时交互状态机 (State Machine) | **现代可交互动画终极形态**。不同于传统视频或死板播放，动画能够根据用户的滑动、长按、输入错误实时改变状态，体积仅几十KB，支持 iOS/Android/Flutter 原生运行时。 |
| **LottieFiles** | [lottiefiles.com](https://lottiefiles.com/) | JSON 矢量动画格式 | 行业事实标准，海量免版税点赞心碎、下拉刷新、加载动画 (Spinner)、支付成功彩带喷洒动效。 |
| **Motion (Framer Motion)** | [motion.dev](https://motion.dev/) | React / Web 物理弹簧动效 | 移动端 H5 与跨端应用神器。声明式 `spring` 物理弹簧曲线，抹平生硬的线性过渡。 |
| **Animate.css** | [animate.style](https://animate.style/) | 纯 CSS 动效合集 | 经典轻量，用于卡片淡入上浮 (`fadeInUp`)、抖动警告 (`shakeX`) 等单次触发动画。 |

## ⚡ 移动端微动效设计铁律
1. **持续时间 (Duration) 黄金区间**：
   - 界面小部件微动效（如按钮缩放、开关切换）：`100ms ~ 200ms`；
   - 视图级转场（如 Modal 抽屉滑出、页面推入）：`250ms ~ 350ms`；
   - 任何超出 `400ms` 的非必要动画都会让用户产生明显的“卡顿迟滞感”（详见 [[05 - 多尔蒂门槛 (Doherty Threshold) 与微动效反馈]]）。
2. **拒绝无意义动效**：
   - 动效的三大核心使命：**解释空间层级关系**（从哪来回哪去）、**提供物理操作反馈**（告知已被系统接收）、**转移等待焦虑**（加载趣味骨架）。
